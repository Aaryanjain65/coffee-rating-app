ABOUT THE APP

CoffeeRate

CoffeeRate is a web-based coffee discovery and rating platform created for people who want to explore different types of coffee in one place.

The application provides information about coffee varieties, their origin, roast level, community rating, and number of votes. Users can search, filter, compare, and vote for coffees they like.

What You Can Do

CoffeeRate makes it easier to explore coffee varieties and understand community preferences.

R

Rate Coffee

Vote for coffees you enjoy. Your vote contributes to the community rating and helps other users discover popular coffees.

V

View Ratings

Check the current rating and vote count of different coffees before deciding which coffee you want to explore.

S

Search & Explore

Search the coffee collection using coffee name, origin, or roast information and quickly find the coffee you are looking for.

A

User Account

Create an account and securely log in to access the CoffeeRate platform and its coffee collection.

COFFEE INFORMATION

Discover coffee from different origins.

Every coffee in the collection contains useful information such as its name, origin, roast level, rating, and number of votes.

The origin information helps users understand where a coffee comes from, while the roast level provides an idea about the style of the coffee. Users can then compare ratings and votes to explore the collection.

How It Works

A simple process for discovering and rating coffee.

01. Create an Account

Register using your name, email, and password. After registration, log in to access the CoffeeRate platform.

02. Explore Coffees

Browse different coffee varieties and view their origin, roast level, rating, and votes.

03. Search & Filter

Use the search box and filter options to find specific coffees or arrange them by rating, votes, or name.

04. Vote for Coffee

Select a coffee you enjoy and vote for it. The vote count and rating are updated in the application.

WHY COFFEERATE?

A simple way to explore coffee.

CoffeeRate brings coffee information and community ratings together in a single platform.

Instead of searching through different sources, users can browse the available coffee collection, compare ratings, search by origin, and vote for their preferred coffee.

Technology Used

CoffeeRate uses a simple full-stack web architecture.

UI

Frontend

HTML, CSS and JavaScript are used to create the interface, coffee cards, search, filters, navigation and interactive features.

API

Backend

Node.js and Express.js handle the application server, API requests, authentication and coffee voting.

DB

Database

SQLite is used to store coffee information, ratings, votes and registered user data.

SEC

Password Security

User passwords are stored using bcrypt hashing rather than storing the original password directly.
